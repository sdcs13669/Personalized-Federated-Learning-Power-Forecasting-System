# 差分隐私参数计算过程与原理说明

Date: 2026-08-15（机制更新为客户端 DP-SGD）

本文档解释 `fl_code/train_baseline.py` 中 DP-FedAvg 三个参数
（`--dp-noise` σ、`--dp-clip` C、`--dp-delta` δ）的计算依据，
以及隐私预算 ε 的完整推导过程。所有数值均可通过
`_compute_epsilon()`（train_baseline.py，基于 Opacus
`compute_rdp` / `get_privacy_spent`）复现。

## 0. 目标与约定

- 隐私预算控制目标（主方案文档）：**ε ≤ 8，δ = 10⁻⁵**
- DP 机制：**客户端本地 DP-SGD**——每个客户端在自己的本地训练中对
  **每个样本的梯度**（per-sample gradient）做固定裁剪 + 高斯加噪，
  训练结束后只上传模型更新；服务器仅做聚合（后处理），即使服务器
  不可信也无法还原任何客户端的原始数据或未加噪梯度
- 采样放大：每个 SGD 步从本地数据集随机抽一批（B 个窗口），采样率
  **q = B/n**（n = 该客户端训练窗口数）——这是 DP-SGD 隐私预算的主要来源
- 训练规模：每客户端每轮 `ceil(n/B) × local_epochs` 步，共 T 轮

## 1. (ε, δ)-差分隐私定义

机制 M 满足 (ε, δ)-DP，当对任意相邻数据集 D、D'（差一条记录）和
任意输出集 S：

```
Pr[M(D) ∈ S] ≤ e^ε · Pr[M(D') ∈ S] + δ
```

- ε：隐私损失上界，越小越私密
- δ：违反 ε 保证的最大允许概率（本项目 δ = 10⁻⁵）

## 2. 客户端 DP-SGD 机制与灵敏度（为什么 ε 与 C 无关）

DP-FedAvg 每轮流程（隐私操作全部在客户端本地完成）：

1. 客户端 i 下载全局模型 θ_global
2. 本地 DP-SGD 训练 Sᵢ = ceil(nᵢ/B) × epochs 步，每步：
   - 随机抽 batch（大小 B，采样率 q = B/nᵢ）
   - 对 batch 内每个样本**单独**计算梯度 gⱼ（torch.func `vmap(grad)`
     实现；不用 opacus 的 GradSampleModule——它与 weight_norm 参数化卷积
     不兼容）
   - per-sample 裁剪：`clip(gⱼ, C) = gⱼ · min(1, C/‖gⱼ‖₂)`，
     强制每个样本的梯度 l2 范数 ≤ C
   - 聚合加噪：`g̃ = (Σⱼ clip(gⱼ) + N(0, (σC)²I)) / B`
   - 优化器用 g̃ 更新参数
3. 上传更新：Δ̃ᵢ = θᵢ_final − θ_global
4. 服务器仅做聚合（后处理）：θ_new = θ_global + Σ wᵢ·Δ̃ᵢ

**灵敏度推导（样本级相邻分析）**：相邻数据集差一条本地样本。
每步发布的统计量 Σⱼ clip(gⱼ) 中，单个样本的贡献最多变化 C（l2 范数）
——裁剪保证。噪声 std = σC → **noise multiplier = σ**，与 batch 大小、
聚合权重 wᵢ 均无关。

结论：**ε 只由 σ、每步采样率 q = B/n、总步数 S_total、δ 决定，
与 C 无关**（灵敏度和噪声同乘 C，相互抵消）。C 只影响裁剪偏置
（精度），是独立于隐私的精度旋钮。

注：加噪发生在梯度均值上（每步噪声 σC/B），而非最终更新上。这是
DP-SGD 与"对最终更新一次性加噪"的本质区别：前者利用 B/n 采样放大，
把每步隐私开销降到 O(q²/σ²) 量级，本项目的 ε≤8 预算因此才可行
（旧机制对 2.9 万参数模型每轮注入 ~σC·√(Σwᵢ²) ≈ 2.0 的参数噪声，
2~3 轮即淹没模型）。

## 3. 子采样高斯机制的 RDP（每步）

Rényi 差分隐私：机制 M 满足 (α, ε_RDP)-RDP，当 α 阶 Rényi 散度
D_α(M(D) ‖ M(D')) ≤ ε_RDP。

对无子采样（q = 1）的高斯机制（灵敏度 Δ、噪声 std σΔ），RDP 有
闭式解：

```
ε_RDP(α) = α / (2σ²)
```

本项目每步是 **B/n 子采样 + 高斯噪声**，RDP 没有简单闭式（上式是
q=1 的特例），Opacus 用数值方法精确求值（`compute_rdp`）。要点：

- q 越小、放大越强：小 q 时 ε_step(α) ≈ q²·α/(2σ²)，比无子采样
  小 q² 倍
- q 不太小时（本项目最小客户端 n≈2305、B=64 → q≈0.028），高阶项
  使放大不完全，手算 q² 近似会低估 ε 数十倍，**必须以 Opacus 数值为准**

## 4. 组合定理（步数 × 轮数线性相加）

RDP 对组合可加。每个客户端的总步数 S_total = ceil(n/B) × epochs × T：

```
ε_RDP(α) = S_total × ε_step(α; q, σ)
```

所有客户端取最坏值（数据集最小的客户端 q 最大、通常主导）。

## 5. RDP → (ε, δ) 转换（Balle et al. 2020 定理 21）

Opacus 采用 Balle《Hypothesis testing interpretations and Rényi
differential privacy》(AISTATS 2020) 定理 21 的紧化转换。
对每个 α > 1 给出一个可行 (ε, δ) 对：

```
ε(α) = ε_RDP(α) − (ln δ + ln α)/(α − 1) + ln((α − 1)/α)
```

取所有 α 中的最小值：

```
ε* = min_{α>1} ε(α)
```

注意：教科书版 `ε_RDP − ln(δ)/(α−1)` 缺少
`−ln α/(α−1) + ln((α−1)/α)` 两项，界更松，手算结果会大于
Opacus 输出，属于正常现象。

## 6. 数值示例（σ = 1.0，B = 64，T = 30，δ = 10⁻⁵）

最坏客户端（tetouan/steel，n ≈ 2305）：

```
q = 64 / 2305 ≈ 0.0278
S_total = ceil(2305/64) × 1 × 30 = 1110 步
Opacus 输出：ε = 6.53（α* 在 1.1~63 网格上搜索）
```

最大客户端（eld_ind_0，n = 1,453,906）：

```
q ≈ 4.4e-5，S_total ≈ 681,510 步
Opacus 输出：ε ≈ 0.44
```

系统级 ε = max（各客户端）= 6.53 ≤ 8 ✓。

## 7. 参数对照表与推荐配置

同一计算对不同 (B, σ, T) 重复（δ = 10⁻⁵，ε 取最坏客户端）：

| B | σ | T | ε | 是否满足 ε ≤ 8 |
|---|-----|---|-------|----------------|
| 64 | 0.75 | 30 | 12.51 | ✗ 超预算 |
| 64 | 1.0 | 30 | 6.53 | ✓ |
| 64 | 1.5 | 30 | 3.28 | ✓（留余量） |
| 64 | 1.0 | 20 | 5.32 | ✓ |
| 32 | 1.0 | 30 | 4.29 | ✓ |
| 16 | 0.75 | 30 | 5.66 | ✓ |

推荐命令：

```bash
# 20 轮（默认轮数），ε≈5.3
python -m fl_code.train_baseline --dp-noise 1.0 --dp-delta 1e-5

# 30 轮，ε≈6.5
python -m fl_code.train_baseline --rounds 30 --dp-noise 1.0 --dp-delta 1e-5

# 30 轮，更大隐私余量 ε≈3.3
python -m fl_code.train_baseline --rounds 30 --dp-noise 1.5 --dp-delta 1e-5
```

- σ 是隐私旋钮：ε 随 σ 增大而减小（约按 1/σ² 比例）
- ε 随轮数近似线性增长（RDP 可加；Balle 转换后略低于线性）
- B 增大会减少步数（训练更快），但 q = B/n 增大，ε 近似随 B 线性增大
- C 是精度旋钮：默认 1.0。本项目 per-sample 梯度范数典型值 ~1-2，
  C 过小产生裁剪偏置（相当于缩小学习率），C 调大则噪声 σC 同比例
  增大——**ε 不变**
- 训练启动时脚本会打印本轮配置对应的 ε，微调 σ 后重跑即可校准
- **效用代价是诚实的**：每步噪声 σC/B 直接进入梯度均值，ε≤8 下
  最小客户端（n≈2305）的 DP 模型精度会低于 nodp 基线（30 轮实测
  WAPE≈0.41 vs nodp≈0.3），大客户端（n≳66 万）几乎不受影响——
  这是小数据集上差分隐私的固有代价

## 8. 原理一句话总结

每个客户端在本地以 DP-SGD 训练：每步对 batch 内逐样本梯度裁剪
（灵敏度 C）并加高斯噪声（std σC，乘子 σ），B/n 子采样提供放大；
S_total 步 RDP 线性相加后经 Balle 定理 21 转换、对 α 取最小，即得
该客户端隐私预算 ε；所有客户端取最坏值。给定目标 ε 与 δ 即可反解
所需 σ。
