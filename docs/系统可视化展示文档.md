# 系统可视化展示文档

> 版本：v1.0
> 目标读者：项目全体成员
> 关联文档：《基于隐私保护多方协同训练的用电量预测系统方案.md》

---

## 1. 定位

**web 展示 = 单机联邦模拟 + 可视化外壳**。展示层不承载真实分布式系统，只呈现单机模拟的训练状态与学习效果。

```
Streamlit 展示层（浏览器）
   │  读训练状态、触发按钮
   ▼
单机模拟引擎（后端 Python 进程）
   ├─ 5 个虚拟参与方（各自数据分片 + 本地模型 + 本地头）
   └─ 中心服务器（聚合 + DPSGD 加噪）
```

## 2. 展示页面

| 页面 | 内容 |
| --- | --- |
| 数据总览 | 5 类参与方各自的私有数据分别展示，证明原始数据本地留存 |
| 训练监控 | 参与方在线状态、训练轮次、损失收敛曲线、ε 隐私预算消耗 |
| 效果对比 | 真实曲线 vs 本地模型 vs 标准 FedAvg vs 个性化联邦（预测图 + WAPE/MAE） |
| 隐私权衡 | 不同 ε 下 WAPE / 成员推断攻击 AUC 变化曲线 |
| 容错演示 | "模拟断线"按钮，点击后某参与方离线，训练不中断 |

## 3. 技术选型

- 展示层：Streamlit（单文件式开发，无需前后端分离、无需数据库）
- 后端：单机 Python 模拟器（FedAvg + 共享 TCN + 本地头 + DPSGD）
- 运行形态：一个 Python 进程，浏览器访问，笔记本可跑

## 4. 数据流向

模拟器实时输出训练状态（损失、轮次、在线名单、ε、各模型预测）→ Streamlit 定时读取渲染；按钮触发模拟器动作（开始训练、断开参与方）。

## 5. 不在范围内

- 不建完整 web 应用（无 Vue/React、无 PostgreSQL、无 Prometheus/Grafana）
- 不做多设备分布式部署（必要时模拟器换成 Flower 真服务器，展示层不动）
