# 个性化预测模型设计（草案）

> 版本：v1.0
> 适用范围：个性化联邦学习 + 差分隐私的电力负荷预测系统
> 目标读者：项目全体成员

---

## 1. 目标

聚合中心训练一个**全局模型**预测宏观趋势；每个客户端在全局模型基础上挂一个**个性化本地头**，用本地数据纠正残差，实现个性化预测。

## 2. 总体架构

```
                聚合中心
              ┌────────────┐
              │  全局模型    │  ← 只使用公共特征，联邦聚合更新
              └─────┬──────┘
                    │ 共享全局输出
       ┌────────────┼────────────┐
       ▼            ▼            ▼
   客户端 A       客户端 B      客户端 C
   全局模型  +    全局模型  +   全局模型  +
   本地头 A       本地头 B      本地头 C
   (公共特征 +   (公共特征 +   (公共特征 +
    本地特征)     本地特征)     本地特征)
```

- **全局模型**：用所有客户端的公共特征训练，联邦聚合更新，预测宏观趋势；
- **本地头**：接受全局模型输出 + 本地独有特征，预测最终功率（残差纠正），只在本客户端训练，永不上传。

## 3. 特征分工

| 层次 | 特征 | 说明 |
|---|---|---|
| 公共特征（全局模型） | 时间戳派生特征：小时、星期、节假日、季节性；类别（res/ind） | 所有客户端都有，参与联邦聚合 |
| 本地特征（本地头） | 目标滞后值、数据集专有列（电压、无功、天气等） | 每个客户端自己的数据，只进本地头 |

特征分工同时解决了不同开源数据集特征不对齐的问题：全局聚合只碰公共特征，特征空间天然一致。

## 4. 训练流程（两阶段）

1. **联邦阶段**：在公共特征上训练全局模型，正常联邦聚合；
2. **个性化阶段**：冻结全局模型参数，仅用本地数据训练各客户端的本地头。

**注意**：本地头的梯度不能回流进全局模型，防止个性化过拟合污染共享模型。

## 5. 两级个性化

工业与居民用电的时序特征差异大，单一全局模型会"平均到无意义"：

- **类别级**：res/ind 各训练一个全局骨干（或把类别作为公共特征做条件）；
- **客户端级**：类别内每个客户端各有一个本地头。

对应项目立意：异类数据间体现特征差异，同类数据间体现个体差异。

## 6. 隐私

- 本地头携带的本地特征永不出客户端；
- 差分隐私噪声只作用于公共特征上的全局更新，隐私面小。

## 7. 评估

分两档报告预测误差：

1. 全局模型单独预测的误差（基线）；
2. 加上本地头后的误差（个性化）。

两者差距即个性化带来的增益。
