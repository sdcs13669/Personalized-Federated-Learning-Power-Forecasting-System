# 项目落地计划

> 版本：v1.1
> 目标读者：项目全体成员
> 定位：从数据采集到系统落地的分阶段路线图

---

## v1 范围界定

- **纳入**：MQTT/HTTPS 通信链路、可控使用（联邦学习 + 差分隐私）、审计日志
- **后期**：可信采集（需硬件支持）、区块链上链、DID 数字身份
- **部署形态**：单机模拟 → Docker Compose 容器路线（满足交付"部署镜像"要求）

## 各阶段详情

### 阶段 1：数据采集与清洗

- 按《完整数据处理管线.md》选数据集、入库 raw → processed
- 写 manifest 与质量报告

### 阶段 2：联邦基线

- 实现 GlobalTCN 点预测模型（PyTorch）
- 按客户端配置切分数据，**跨域 FedAvg 聚合训练 GlobalTCN**（不加 ResidualCorrector）
- 模型仅使用 8 个公共特征（时间派生 + category_id），不引入本地特征
- 产出 `Y_pre` 的 WAPE/MAE 基线
- 基线是后续个性化（Phase 3）的对照靶子：`Y_final vs Y_pre` 的差值直接量化个性化修正的增益

### 阶段 3：联邦模拟 + 个性化（可控使用核心）

- 数据按参与方切分（participant_id）
- FedAvg / FedProx + 共享 TCN 编码器 + 本地个性化头
- 三组对比：本地模型 / 标准 FedAvg / 个性化联邦

### 阶段 4：差分隐私 + 隐私评估（可控使用核心）

- DPSGD：L2 裁剪 + 高斯噪声 + 隐私会计器
- 产出 ε-WAPE、ε-AUC 权衡曲线

### 阶段 5：通信链路 + 审计日志

- 采集端用脚本模拟上报（MQTT / HTTPS），不依赖硬件
- 联邦模型更新走 HTTP / gRPC 传输
- 服务器记录审计日志：参与方在线状态、更新接收、ε 消耗、模型版本
- Docker Compose 编排 1 server + N client 容器，单机可跑

### 阶段 6：可视化展示

- Streamlit 五页面：数据总览、训练监控、效果对比、隐私权衡、断线演示
- 展示层只读系统状态，不承载分布式逻辑

### 阶段 7：演示与材料交付

- 演示脚本、录屏、对比图、评估报告
- 逐项核对方案文档 §十七 提交清单

## 执行原则

- 阶段 1、2 可并行
- 每阶段产出文档/图，作为答辩材料
- 阶段 5 依赖 3/4 的模拟器；阶段 6 依赖 5
- v1 不做硬件可信采集与区块链上链，需在演示中说明为后续方向
