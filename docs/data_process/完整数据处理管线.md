### 阶段 2：数据清洗

统一 10 步清洗流水线，脚本位于 `data/scripts/clean-feature-engneer/`。

| 步骤          | 操作                              | 说明                       |
| ------------- | --------------------------------- | -------------------------- |
| 1. 时间解析   | 多格式兼容                        | dayfirst 自动检测          |
| 2. 重采样     | 统一 30min（mean）                | 原始 10/15min → 30min     |
| 3. 首部修剪   | 截断前导零                        | 设备投运前时段 → NaN      |
| 4. 连续性过滤 | raw gap > 48 步丢弃               | 24 小时以上空白            |
| 5. 异常检测   | 标签 diff IQR / 特征 rolling IQR  | 系数 2.5（steel 标签 3.0） |
| 6. 物理裁剪   | 功率>0, PF[0,1]                   | 数据集特定                 |
| 7. 二次过滤   | post gap > 48 步丢弃              | 清洗后残留大缺口           |
| 8. 插值填充   | cubic spline, limit_area="inside" | 仅填补内部缺口             |
| 9. 物理裁剪   | 再次校验                          | 防插值溢出                 |
| 10. 特征工程  | 派生公共时间特征                  | —                         |

**清洗结果（4 套 processed CSV）：**

| 数据集       | 清洗后规模           | 剔除序列 | 缺失率 | 脚本                  |
| ------------ | -------------------- | -------- | ------ | --------------------- |
| eld_ind      | 361 MT × 70,129 行  | 9        | 19.15% | clean_eld_ind.py      |
| lcl_res      | 321 MAC × 39,727 行 | 9        | 0.38%  | clean_lcl_res.py      |
| steel_ind    | 17,520 行            | 0        | 6.4%   | clean_steel_ind.py    |
| tetouan_city | 17,472 行            | 0        | 0%     | clean_tetouan_city.py |

异常检测策略：

- **标签（功率）**：diff IQR — 检测物理上不可能的变化速率，保护正常峰值
- **特征（气象/无功/CO2）**：rolling IQR（窗口 336 步）— 检测相对局部模式的偏离

### 阶段 4：特征筛选

使用 XGBoost + SHAP，脚本位于 `data/scripts/feature-select/`。

| 数据集       | 方法             | R²          | 筛选结果                                           |
| ------------ | ---------------- | ------------ | -------------------------------------------------- |
| steel_ind    | 单目标 SHAP      | 0.834        | 6→4 维（剔除 leading_reactive_power、leading_pf） |
| tetouan_city | 3 Zone 各自 SHAP | —           | 5 维全保留（VIF<5）                                |
| eld_ind      | 326 MT 聚合 SHAP | median 0.729 | 无本地特征可选                                     |
| lcl_res      | 321 户聚合 SHAP  | median 0.224 | 无本地特征可选                                     |

关键发现：lcl_res 的时间特征解释力极弱（R² median=0.224），验证了个性化残差修正器的必要性。8 个公共特征为固定 encoder 输入，不参与剔除。

筛选报告位于 `data/feature_selection/`（6 份 YAML + 汇总报告）。

### 阶段 6：训练/测试集划分

统一采用**逐序列 80/20 时间顺序切分**，不设验证集。

- 每序列独立在自身有效范围内按 `train_ratio=0.8` 切分
- 禁止随机打乱，保证时间因果性
- 多序列客户端（eld/lcl）中每条序列各自独立切分

实现：`split_train_test(df, seqs)` → 返回 `train_df`、`test_df`（对方部分 mask 为 NaN）。

### 阶段 7：数据预处理

实现于 `fl_code/data_utils.py`：`preprocess(df, seqs, local_cols)`。

**负荷（功率）列 — 逐序列：**

1. log1p 对数化
2. 均值-标准差归一化：(y - mean) / std
3. 统计量仅基于有效（非 NaN）值计算

**本地特征列 — 逐列：**

- 均值-标准差归一化：(x - mean) / std
- 统计量仅基于有效值计算

**公共特征：**

- 时间特征（7 维）：已处 [-1,1]，无需归一化
- 类别独热（3 维）：{0,1}，无需归一化

**独热编码：**

- `load_client_data()` 自动将 CSV 中的 `category_id` 展开为 3 维独热
- 映射：0→[1,0,0]、1→[0,1,0]、2→[0,0,1]

**FL 隐私合规：** 归一化统计量按每序列/每列独立计算，不跨序列借用信息。
