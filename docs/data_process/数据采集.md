# 数据采集规范

> 版本：v1.0
> 适用范围：个性化联邦学习 + 差分隐私的电力负荷预测系统 —— 开源数据集收集阶段
> 目标读者：项目全体成员（含大一新成员）
> 关联文档：《数据清洗规范.md》（raw → processed 的清洗流程）

---

## 0. 原则

> **原始数据永不修改；每一份进入项目的数据都必须有来源、有许可、可溯源。**
> 本规范相对稳定；清洗方法需随具体数据特征调整，见《数据清洗规范.md》。

---

## 1. 目标与适用范围

本规范规定了"开源数据收集阶段"的两件事：

1. **选**：如何选取可靠的开源电力数据集；
2. **交**：采集到的原始数据如何命名、存放、登记，供后续清洗使用。

清洗（raw → processed）不在本规范内，见《数据清洗规范.md》。

---

## 2. 角色与职责

3个人负责某个数据集的采集、命名、登记、质量报告编写.按《数据清洗规范.md》验收清单复核提交的数据是否合规、可复现

## 3. 数据集选取标准

选取一个数据集，必须**同时**满足以下条件：

| # | 标准                 | 说明                                     | 验收方式                                                                   |
| - | -------------------- | ---------------------------------------- | -------------------------------------------------------------------------- |
| 1 | 开源可获取           | 有公开、稳定的下载入口                   | 记录 source_url + 下载日期                                                 |
| 2 | 许可允许使用与再分发 | 用于团队共享与后续研究/开源              | 记录 license 名称与原文链接；许可原文存入 `data/raw/<数据集ID>/LICENSE*` |
| 3 | 元数据完整           | 有单位、分辨率、传感器说明、采集时间范围 | 全部抄录进 manifest.yaml                                                   |
| 4 | 与项目主题相关       | 属于工业用电或居民用电的负荷序列         | 能判定类别（res/ind）及序列含义                                            |
| 5 | 规模合适             | 数据量在团队计算与存储能力内             | 记录条数与文件大小                                                         |

**不建议使用的数据源**：来源不明的爬虫数据、无法给出许可依据的数据、已经被他人二次加工且无法溯源的数据。

## 4. 目录结构

### 4.1 目录结构

```
data/
├── raw/                    # 原始数据，只读，永不被清洗脚本修改
│   └── <数据集ID>/
│       ├── <原始文件名>     # 原封不动拷贝
│       └── LICENSE*         # 许可原文（如有）
├── processed/              # 清洗后数据，供训练使用
│   └── <数据集ID>.csv
└── manifests/              # 每个数据集一份清单
    └── <数据集ID>.yaml
```

### 4.2 数据集 ID 命名

- 形式：`源名_类别`，全小写，下划线连接。
- 类别为 `res`（居民 residential）或 `ind`（工业 industrial）。
- 示例：`lcl_res`、`ukdale_res`、`pjm_ind`。

### 4.3 关联文件命名

- 清洗脚本：`scripts/clean_<数据集ID>.py`，与 manifest 一一对应。

---

## 5. 数据清单（manifest.yaml）

每个数据集一份 manifest，只描述**原始数据本身**，不含客户端划分、统一模式等后续建模信息。

```yaml
dataset_id: lcl_res
name: Low Carbon London
source_url: ...
timestep: 1800 s       # 原生采样间隔和单位
category: res                    # res | ind
description: ...
features:                  # 原始特征
  - {raw: "tst",  unit: "iso"}
  - {raw: "KWH", unit: "kwh/halfhour"}
```

字段说明：

| 字段            | 必填 | 说明                     |
| --------------- | ---- | ------------------------ |
| `dataset_id`  | 是   | 见 4.2                   |
| `name`        | 是   | 数据集全名               |
| `source_url`  | 是   | 公开下载入口             |
| `timestep`    | 是   | 原生采样间隔和单位       |
| `category`    | 是   | res（居民）/ ind（工业） |
| `description` | 是   | 来源、覆盖范围、采集说明 |
| `features`    | 是   | 原始特征列名与单位       |
