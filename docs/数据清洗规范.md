# 数据清洗规范

> 版本：v1.0
> 适用范围：个性化联邦学习 + 差分隐私的电力负荷预测系统 —— 开源数据收集阶段
> 目标读者：项目全体成员（含大一新成员）
> 关联文档：《数据采集规范.md》（选数据集、raw 存放、manifest、序列语义）

---

## 0. 原则

> **原始数据永不修改，清洗过程必须可复现，每一份进入训练的数据都必须有质量报告。**
> 清洗方法与阈值不写死，**根据具体数据集的特性选择**（见第 2 节），本规范提供框架与默认规则。

---

## 1. 目标与适用范围

本规范规定了 raw → processed 的清洗全流程：

1. 清洗前如何**分析数据特性并制定清洗方案**（这是本规范的核心，先看数据再定方法）；
2. 清洗的**标准流程**（含异常值清洗与特征筛选）；
3. **质量评估与验收**，作为数据入库的门槛。

本规范不涉及模型训练、联邦聚合与差分隐私加噪（那是后续阶段的事），
但所有清洗规则都遵循一条底线：**不引入跨客户端的数据泄漏**（见第 5 节）。

> 铁律：**先复制到 raw 再清洗，raw 永远不动；所有改动用脚本完成并留档，禁止手工改数。**

---

## 2. 清洗前的准备：数据特征分析与清洗方案设计

清洗方法取决于**找到的数据是什么样**。每个数据集在清洗前，先回答下表问题
（答案来自 manifest 与对 raw 数据的探查，即 EDA），再据此选择各步方法。

| 特征项 | 需确认内容 | 影响的清洗步骤 |
|---|---|---|
| 原生分辨率 | 采样间隔、是否均匀 | §3 重采样 |
| 时区/夏令时 | 原始时区、是否跨 DST | §4 时间戳标准化 |
| 单位 | 功率单位是否 kW、时间戳格式 | §5 加载与类型检查 |
| 缺失表达 | 空 / NaN / 0 / 无记录，用哪种表示 | §7 缺失值处理 |
| 负值语义 | 是否有分布式光伏并网（净计量） | §8 异常值清洗 |
| 序列语义 | 每条序列代表什么（家庭/工厂/产线…） | 客户端划分（见采集规范 5.3） |
| 初筛质量 | 初步缺失率、重复率、零值占比 | 是否直接清洗、是否需拒收 |

确定方案后填写**清洗方案表**（模板见附录 A），经评审确认后按方案执行；
执行中若发现与预期不符的特征，回改方案并说明原因。质量报告记录的是"实际做了什么"，
清洗方案表记录的是"打算怎么做及为什么"。

---

## 3. 加载与类型检查

- 用脚本读取，检查每列类型、行数、列名是否与 manifest 文档一致；
- 类型错误（如时间戳被读成字符串）先修正，不要直接丢弃数据。

---

## 4. 时间戳标准化

- 统一转成 UTC，丢弃时区/夏令时歧义（在原时区记录到 manifest）；
- 排序 → 查重：
  - 完全重复的行：保留第一条，记录删除条数；
  - 时间戳重复但数值不同：以先到的为准并记录，异常频发则整段降级。

---

## 5. 重采样（按采集规范 5.4 决定的统一分辨率）

- 从原始间隔聚合到统一分辨率：可取均值（负荷序列默认均值聚合）；
- 重采样产生的空档先置 NaN，交给 §7 处理。

---

## 6. 特征筛选（重点）

区分两个概念：

- **特征工程**（建模阶段做）：由现有列派生时间特征（小时、星期、节假日、滞后值、滚动均值）。本规范只要求数据达到"可建模"，派生特征放建模脚本，不进 processed。
- **特征筛选**（本步）：决定哪些列进入 processed。标准如下：

| # | 筛选规则 | 阈值示例 |
|---|---|---|
| 1 | 缺失率过滤 | 缺失率 > 20% 的列默认剔除（需管理员确认） |
| 2 | 常量/近常量过滤 | 方差≈0（唯一值个数 ≤ 5）的列剔除 |
| 3 | 相关性去重 | 与 `active_power_kw` 相关系数 |
| 4 | 共线性控制 | 多个候选特征间 VIF > 10 时，剔除之一（VIF 公式见附录 B） |
| 5 | 语义要求 | 保留列必须能在 manifest 中给出物理含义与单位，否则剔除 |

> 筛选只作为**数据入库**时的把关，不是建模时的最终特征选择；但**清洗阶段剔除的特征不参与任何训练**，因此规则要保守（宁留勿删，防止丢失个性化信息）。

---

## 7. 缺失值处理

按缺口长度分级处理，规则如下：

| 缺口长度 L（相对统一分辨率） | 处理方式 |
|---|---|
| L ≤ 1 个间隔 | 线性插值（前后两个有效点之间） |
| 1 < L ≤ 3 个间隔 | 线性插值 + 报告中标记为"插值补全" |
| L > 3 个间隔 | **不插值**，保留 NaN（后续建模阶段用掩码/分段处理） |

**禁止**：对大缺口整体插值（会制造大量虚假规律，污染个性化差异）；用全序列均值填空。

---

## 8. 异常值清洗（重点）

分三层，依次执行：

**8.1 物理界检查**：超出物理可能范围的值直接判为异常

- 居民单相有功：`-0.5 kW ≤ P ≤ 30 kW`（可视数据集调整，写入 manifest）；
- 电压：`180 V ≤ V ≤ 260 V`（中国）/ 以数据集所在地区标准为准；
- 负数有功功率：仅当该数据集存在分布式光伏并网（净计量）时允许负值，否则负值判异常。

**8.2 统计离群检查（滚动窗口版）**：负荷有强日周期性，**不要用全序列整体统计**，要用滚动窗口

- 窗口内 IQR 法：取窗口（建议 ≥ 1 天）内的四分位数 `Q1, Q3`，
  - 正常区间：`[Q1 − 3×IQR, Q3 + 3×IQR]`，区间外为异常；
- 或鲁棒 Z 分数：`z = 0.6745 × (x − median) / MAD`，`|z| > 3.5` 判异常（MAD = 绝对中位差）；
- 与前后相邻点比：单点与前后两个采样点相差超过该窗局部波动的 5 倍标准差，判为尖峰。

**8.3 常值/平台段检查**：连续 `N` 个采样值完全相同（尤其恒为 0 或恒为某一常数）视为传感器故障

- 阈值：连续 ≥ 24 个采样点（30 min 分辨率即 ≥ 12 小时）完全相同 → 该段标记异常。

**8.4 异常处置规则**（按优先级）：

1. 判为异常的孤立点 → 按 §7 缺口规则插值覆盖（通常视为 L=1 缺口）；
2. 异常成段（≥ 3 点连续）→ 整段置 NaN，按 §7 规则处理，不做插值伪造；
3. 物理界越界值 → 截断到边界（clip），记录数量；
4. 任何处置都要在质量报告中写明"数量 + 依据 + 方法"，可复现。

---

## 9. 输出与质量报告

- 按统一模式输出到 `data/processed/<数据集ID>.csv`；
- 每个数据集产出一份质量报告（模板见附录 C），内容包括：来源、处理步骤记录、各级指标数值、异常/缺失处置统计、残余风险说明。

---

## 10. 数据质量评估与验收

### 10.1 量化指标（全部记录到质量报告）

| 指标 | 定义 | 公式/说明 |
|---|---|---|
| 缺失率 | 缺失样本占比 | `缺失数 / 总样本数` |
| 重复率 | 重复时间戳占比 | `重复数 / 总样本数` |
| 最大缺口 | 最长连续缺失间隔 | 以采样间隔为单位 |
| 超阈值缺口比 | 长度 > 3 间隔的缺口占总数比例 | 越高代表可用性越差 |
| 异常点比例 | 第 8 步判定的异常点数占比 | |
| 零值占比 | 全零样本比例 | 居民数据异常偏高需警觉 |
| 常值段占比 | 被判平台段样本比例 | |
| 取值范围 | min / max / 分位数 | 对照物理界检查 |

### 10.2 质量等级与准入线

| 等级 | 条件（任一不满足则降级） | 是否准入 processed |
|---|---|---|
| **A** | 缺失率 < 1%，无重复时间戳，无超阈值缺口 | 直接准入 |
| **B** | 缺失率 < 5%，重复率 < 1%，超阈值缺口占比 < 2% | 准入（报告中说明残留问题） |
| **C** | 不满足 B 或存在整段传感器故障 | **拒收或重大处理后重审** |

### 10.3 提交评审清单（Checklist）

数据提交人自查 + 评审人复核，全部 ✅ 才算完成：

- [ ] 1. raw 中原始文件未被动过
- [ ] 2. manifest.yaml 完整（来源、列映射、序列语义、客户端定义、分辨率）
- [ ] 3. 统一模式列名/单位/时区符合《数据采集规范.md》第 5.1 节
- [ ] 4. 清洗脚本可复现（重跑一遍结果一致）
- [ ] 5. 质量报告含第 3~9 节全部步骤的记录
- [ ] 6. 质量等级 ≥ B
- [ ] 7. 未使用全序列全局统计做任何归一化/插值（无泄漏）
- [ ] 8. 特征筛选理由已记录
- [ ] 9. 数据管理员已在 registry 表登记该数据集

## 11. 面向联邦学习与差分隐私的约束（防泄漏）

1. **归一化/缩放必须按客户端各自计算**：每个客户端用自己的统计量（如各自 min-max），禁止用全数据集或跨客户端的统计量。否则会把客户 A 的信息泄漏给客户 B。
2. **清洗不得跨客户端借用信息**：一个客户的缺失值只能用该客户自身的数据填补。
3. **差分隐私与噪声加在哪里**：差分隐私在训练/聚合阶段对梯度或查询结果加噪，**不在清洗阶段**。清洗阶段不要为了"看起来更平滑"而做会放大噪声敏感度的操作。
4. **个性化语义记录**：客户端划分与理由必须写入 manifest，这是后续个性化建模（按类别 res/ind、按客户端局部微调）的数据依据。
5. **数据版本**：processed 数据一旦入库即视为只读；任何清洗规则变更需新增清洗脚本版本并重跑全流程，禁止在原文件上改。

## 附录 B：常用公式

- IQR：`IQR = Q3 − Q1`，离群区间 `[Q1 − 3·IQR, Q3 + 3·IQR]`
- 鲁棒 Z 分数：`z = 0.6745 · (x − median) / MAD`，`MAD = median(|x_i − median|)`
- 缺失率：`missing_rate = #NaN / N`
- 方差膨胀因子：`VIF = 1 / (1 − R²)`，其中 R² 是某特征对其它特征回归的判定系数；`VIF > 10` 视为强共线性
- 相关系数（Pearson）：`r = cov(x,y) / (σ_x σ_y)`
