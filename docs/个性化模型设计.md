# 个性化预测模型设计

> 版本：v2.1
> 适用范围：个性化联邦学习 + 差分隐私的电力负荷预测系统
> 目标读者：项目全体成员

---

## 1. 目标

聚合中心训练一个**全局 TCN 模型**输出基准点预测 `Y_pre`；每个客户端训练一个**本地残差修正网络**，用本地数据纠正残差，输出三分位数预测 `Y_final = Y_pre + E_corr`。

---

## 2. 总体架构（两阶段）

```
                          聚合中心
                     ┌────────────────┐
                     │  Global TCN     │  ← 联邦聚合 (FedAvg)，仅用公共特征
                     │  输入: 1440步   │
                     │  输出: 336步点预测│
                     └───────┬────────┘
                             │ Y_pre (点预测，所有客户端共享)
          ┌──────────────────┼──────────────────┐
          ▼                  ▼                  ▼
      客户端 A            客户端 B            客户端 C
   Global TCN          Global TCN          Global TCN
        +                   +                   +
   Local Corrector     Local Corrector     Local Corrector
   输入: Y_pre +       输入: Y_pre +       输入: Y_pre +
         近期历史(336步)      近期历史(336步)      近期历史(336步)
         + 本地动态特征       + 本地动态特征       + 本地动态特征
   输出: E_corr [P10,P50,P90] 输出: E_corr            输出: E_corr
        =                   =                   =
   Y_final [3分位数]    Y_final [3分位数]    Y_final [3分位数]
```

### 2.1 阶段一：Global TCN（全局模型，FedAvg 聚合）

| 项目 | 说明 |
|------|------|
| 输入 | 公共特征 8 通道 × 1440 步（30 天 @30min）：7 个时间派生 + 1 个类别特征 |
| 架构 | TCN encoder → global pooling → MLP decoder |
| 输出 | `Y_pre`：336 步（7 天 @30min）点预测 |
| 聚合 | FedAvg 按数据量加权，所有 80 个客户端参与 |
| 损失 | 平均绝对误差（MAE），量纲与负荷单位一致，对离群值鲁棒 |

### 2.2 阶段二：Local Residual Corrector（本地修正网络，永不上传）

| 项目 | 说明 |
|------|------|
| 输入（沿特征维度拼接） | (A) `Y_pre` [336, 1] — 全局模型输出的基准预测 |
|  | (B) 近期真实历史 [336, 1] — 预测起点前 336 步的实际负荷 |
|  | (C) 本地动态特征 [336, D_local] — 数据集特有外生变量 |
| 总输入维度 | [Batch, 336, 2 + D_local] |
| 架构 | 轻量 TCN encoder（3 层、32 通道），输出 3 通道 |
| 输出 | `E_corr`：336 步 × 3 分位数（P10, P50, P90）残差修正 |
| 训练 | 分位数损失（pinball loss），仅本地训练，梯度不回传至 Global TCN |

### 2.3 最终输出

```
Y_final[336, 3] = Y_pre[336] + E_corr[336, 3]
```

三个分位数构造 80% 置信区间 `[P10, P90]`，P50 为点预测。

## 3. 特征分工

| 层次 | 特征 | 使用者 | 说明 |
|------|------|--------|------|
| 公共特征 | 时间派生（hour/dow/month sin/cos + is_weekend）+ category_id | Global TCN | 所有客户端一致，参与联邦聚合 |
| 近期历史 | 预测起点前 336 步真实负荷 | Corrector | 提供近期波动模板 |
| 本地动态特征 | 数据集特有列（电价类型、无功功率、天气等） | Corrector | 仅本地使用，永不上传 |

---

## 4. 训练流程（两阶段解耦）

### 4.1 训练步骤

1. **联邦阶段**：训练 Global TCN（MAE 损失），FedAvg 聚合；
2. **个性化阶段**：冻结 Global TCN 参数，用分位数损失训练各客户端的 Local Corrector。

### 4.2 为什么解耦而不是联合训练

联合训练（Global TCN + Corrector 端到端优化 Pinball 损失）存在三个问题：

**隐私泄漏**：Corrector 梯度回流到 Global TCN 时携带本地特征信息（近期历史 + 本地动态特征）。Global TCN 被 FedAvg 聚合后会分发到其他客户端——Client A 的本地特征通过 Global TCN 参数间接暴露给 Client B。

**评估不可分**：联合训练后无法分离"FL 带来的增益"和"个性化带来的增益"。解耦下 `Y_pre`（纯 FL 基线）vs `Y_final`（加个性化）的差值是清晰的个性化贡献度量。

**FL 公平性**：数据量大的客户端（eld_ind 占比 70%）会主导联合训练的梯度方向，Global TCN 优化目标偏向大客户端。解耦阶段一的 MAE 独立于阶段二的 Pinball，Global TCN 对所有人的服务能力平等。

解耦的本质是用架构设计替代审计：梯度边界就是隐私边界，不需要额外验证。

### 4.3 方案对比

|                | 解耦（当前）                        | 联合 + 只上传 TCN 梯度 |
|----------------|-----------------------------------|-----------------------------------|
| 本地特征泄漏   | **无**（架构保证，无梯度链路）       | 极低（梯度是误差方向，不含 Corrector 权重） |
| DP 兼容        | 可以                              | 可以（TCN 梯度依然 clip + noise） |
| Y_pre 作为基线 | **是**（独立训练的纯 FL 模型）      | 否（Y_pre 被训练成"配合 Corrector"） |
| 实现复杂度     | 两个独立训练循环                     | 一次前传、分裂梯度、两个 optimizer step |
| 性能上限       | 可能略低（两个目标不一致）            | 可能略高（端到端优化同一目标） |

### 4.4 约束

- Corrector 的梯度不能回流进 Global TCN；
- Corrector 的参数和本地特征永不上传服务器。

---

## 5. 两级个性化

工业与居民用电的时序特征差异大：

- **类别级**：`category_id`（0=居民，1=变压器，2=钢铁工业）作为 Global TCN 的输入通道，使单一 encoder 区分不同负荷类型；
- **客户端级**：每个客户端各有一个独立训练的 Local Corrector，使用本地独有特征。

---

## 6. 隐私

### 6.1 解耦训练的隐私保障

- 公共特征（时间派生 + 类别）不携带原始功率值，可安全上传；
- 近期真实历史 + 本地动态特征仅进 Corrector，永不出客户端；
- 差分隐私噪声只作用于 Global TCN 的梯度上传，隐私面小。

### 6.2 梯度反演分析

假设攻击者可以随意获取 Global TCN 梯度，且将训练策略改为**联合训练但仅上传 TCN 梯度**（§4.2 的对照方案），梯度反演是否可行？

**攻击者已知**：

| 信息 | 获取难度 |
|------|---------|
| Global TCN 权重与架构 | 服务器端公开 |
| Corrector 架构 | 公开设计 |
| **Corrector 权重** | **无法获取**（仅本地存储） |
| `Y_pre`（该 batch 的输出） | **无法获取**（仅本地计算） |
| `Y_true`（真实负荷） | **无法获取**（仅本地） |

**为什么不可行**：

攻击者的目标是从 19 万个 TCN 梯度值中反推出 `recent_history`（336 维 × batch）和 `x_local`（336 × D_local × batch）。但链式法则下：

```
∂L/∂(TCN参数) ← ∂L/∂Y_pre ← ∂L/∂Y_final · (I + ∂E_corr/∂Y_pre)
```

`∂E_corr/∂Y_pre` 这个 Jacobian 依赖于攻击者未知的 Corrector 权重（27K 个参数）。同时 Pinball loss 的分段特性、14 层以上的梯度传播深度、多样本 batch，进一步使反演变为一组**未知数远超方程数**的欠定问题。

**对比**：

| | 解耦训练 | 联合 + 仅上传 TCN |
|------|---------|-----------------|
| 反演风险 | **零**（recent_history / x_local 不在 Global TCN 计算图中） | **趋近于零**（数学上不可行，但需要论证） |
| 论证方式 | 架构保证——梯度链路被截断 | 数学论证——欠定方程组 |

解耦的隐私优势在于：不需要依赖"攻击者解不开"的论证，而是通过**构造**消除了梯度链路——`recent_history` 和 `x_local` 从未进入 Global TCN 的计算图，不存在被反演的前提。

## 7. 评估

分三档报告预测误差：

1. **Global TCN 点预测**：`Y_pre` 的 MAE / RMSE / WAPE（基线）；
2. **Global + Corrector P50**：`Y_final[P50]` 的误差（个性化点预测）；
3. **分位数校准**：P10/P90 的实际覆盖率 vs 理论 80%。

三档差距分别量化：全局模型的基线能力、个性化增益、不确定性估计质量。
